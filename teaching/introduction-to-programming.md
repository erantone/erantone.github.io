## Syllabus

General principles of computing and computer program design; modularization techniques; programming languages and their characteristics; use of a high-level programming language; and applications of computing in industrial automation.

## Learning objectives

The course develops students' ability to **design computer programs** and understand basic programming concepts. Students learn the foundations of programming, the principal elements of a programming language, and how to apply them to practical problems using a high-level language.

## Course topics

The sequence below follows the supplied teaching plan, **without semester-specific dates**.

1. What is computing? Introduction to programming and Python
2. Variables, expressions, statements, and debugging
3. Functions and program organization
4. Case study: graphical interface programming
5. Conditionals and recursion
6. Functions that return values
7. Iteration and loops
8. Strings and problem solving
9. Lists and dictionaries
10. Modules, local and global variables, and introductory object-oriented programming
11. Practical programming exercises and problem solving
12. Development and presentation of a programming project (e.g., a game)

## Teaching methods

Classes combine introductory explanations, discussion, and **hands-on programming activities in a computer laboratory**. Readings and videos may be provided as supplementary resources.

## Assessment model

The reference teaching plan specifies:

- **Practical exam 1 (P1):** individual, in person
- **Practical exam 2 (P2):** individual, in person
- **Programming project (T1):** source-code submission and project presentation

The reference grading formula combines the two exams and the project using a weighted geometric mean:

<div class="note">
  <strong>Reference formula:</strong> MFAR = <em>f</em> × ∛[ ((P1 + P2)/2)<sup>2</sup> × T1 ], where <em>f</em> is 1 when attendance is sufficient and 0 otherwise.
</div>

The source plan requires attendance at **at least 75%** of the course hours. It also describes a final recovery examination for eligible students. For the specific rules governing grades, attendance, recovery, and second-chance examinations, **consult the official teaching plan for your term**.
