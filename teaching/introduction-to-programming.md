## Overview

This course introduces algorithmic thinking and basic programming concepts using **Python**, with examples drawn from automation and engineering problems.

Topics commonly covered include:

- Variables, expressions, and basic data types
- Conditional statements and iterative structures
- Functions, parameters, local and global variables
- Lists, dictionaries, and basic data organization
- Program decomposition, debugging, and problem solving

The content above is an **overview of the course's teaching focus**, not a transcription of an official current-semester plan. Specific assessment requirements and course materials depend on the offering.
