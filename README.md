# Eric Aislan Antonelo — Academic website

A lightweight, bilingual-ready **Jekyll** academic site for GitHub Pages, distinct from the GSAI group website. The current version is in English. It features research, publications, teaching, supervision, historical projects and media.

## Quick launch on GitHub Pages

1. Create a repository on GitHub. **Do not upload the ZIP itself.** Unzip `eric-academic-site.zip`, then upload all the *contents* of its main folder to the root of your repository, including `_layouts/`, `_includes/`, `assets/`, `_config.yml` and `index.html`.
2. Edit `_config.yml` to match your repository:
   - If repo is `erantone.github.io`, **the default settings are already correct** (`url: "https://erantone.github.io"`, `baseurl: ""`). For a different GitHub username, change `url` accordingly.
   - If repo is a project repository such as `academic-site`, keep `url: "https://erantone.github.io"` but set `baseurl: "/academic-site"` (use your actual repository name).
   - If using a custom domain, set `url` to the canonical URL and `baseurl: ""`; add a `CNAME` file only after configuring the domain with GitHub.
3. Open repository **Settings → Pages → Build and deployment**; choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Wait for GitHub Pages to publish (you can follow the **Actions** tab). Visit the generated URL. Links are configured with Jekyll's `relative_url` filter to work with repo subpaths once `baseurl` is correctly set.

> This is a Jekyll source site. Opening `index.html` directly from the file browser **does not** correctly render Liquid tags; use GitHub Pages or a local Jekyll server to preview. A separate `preview/` folder is not needed for publication.

## Working locally (optional)

With Ruby/Bundler and the [GitHub Pages dependency bundle](https://github.com/github/pages-gem) installed:

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`. On a project repo site, you may temporarily set `baseurl: ""` to preview under the root, or visit the path with your configured baseurl.

## Content notes / editorial decisions

- The **Machine Learning (DAS410058)** and **Generative Artificial Intelligence (DAS410116)** pages were derived from the supplied teaching plans. Class dates, classrooms, holiday closures and semester labels were intentionally removed. Syllabi, credit counts, topic coverage, course prerequisite, assessment split and reading lists were retained as indicated by those plans.
- The **DAS5334** page is an initial overview based on previously described course topics, **not** a replacement for its current official teaching plan.
- Historical offerings from Drupal are listed in `teaching/archive.md`, but missing PDFs and unverified links have intentionally not been published. Some captured Drupal pages were duplicates generated by filters.
- The portfolio and media sections contain **curated summaries**, not verbatim migration of old Drupal pages.
- The GSAI website continues to represent the **research group**; this site represents the **individual academic career and teaching**. Current group content links to GSAI rather than being duplicated.
- Do **not** point links to the lost domain `ericantonelo.com`. Review third-party rights and versions before publishing PDFs or images recovered from the Drupal backup.
- The contact email is assembled by JavaScript rather than written into the HTML. This only discourages simple scraping; it is not a strong anti-spam measure.
